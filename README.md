
# WakilPlus
## نظام الوكيل التمويني العراقي

تطبيق لإدارة الوكلاء التموينيين في العراق.

### المميزات
- إدارة المستفيدين والعوائل.
- إدارة الحصة الغذائية.
- إدارة الطحين.
- إدارة الرعاية الاجتماعية.
- إدارة التسليم.
- الحسابات والديون.
- مقارنة قوائم PDF.
- التقارير والإحصائيات.
- العمل دون إنترنت.
- دعم QR و NFC.

الإصدار الأول: 1.0.0
